Settings

GitHub token

Locked with your Mac's Keychain. It is never shown again and never leaves this Mac except to talk to GitHub.

How do I make a token?
  1. Open github.com → Settings → Fine-grained tokens → Generate new token.
  2. Name: DualFlow Mac app. Expiration: 90 days (or what you like).
  3. Repository access: Only select repositories → dualflow-ai.
  4. Permissions → Repository permissions → Actions: Read and write. Nothing else.
  5. Press Generate token, copy it, paste it above, press Save token.
